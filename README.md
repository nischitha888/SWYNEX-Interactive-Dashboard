## 📌 Project Overview

The HR Workforce Analytics Dashboard is an interactive data analytics project developed using Microsoft Excel. It transforms HR data into meaningful visual insights through KPI summaries, PivotTables, charts, formulas, and interactive filters.

The dashboard provides a structured view of workforce information, making key HR metrics easier to explore and interpret.

## 🎯 Project Objectives

- Analyze employee distribution and workforce composition.
- Explore gender, department, and regional data.
- Examine salary information across job roles.
- Summarize employee skills and performance indicators.
- Analyze leave-related metrics.
- Present HR insights through interactive visualizations.
